# Garbage Collection

整理日期：2026-11-14

GC 挑選待回收 Block，先把仍有效的 Page 搬到安全位置並更新 mapping，才 erase 原 Block。Invalid Page 不需保留。搬移也會發生 NAND 寫入，因此 GC 並非零成本。

## 教學模型與邊界

原創示例：B0=[A舊,B有效,C有效,D失效]。搬移 B、C 兩頁後，B0 才能整體擦除。任何 erase 前漏搬有效頁都會遺失資料。
