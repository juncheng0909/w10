## 關鍵概念（自行改寫）

Host 使用 LBA。FTL 將邏輯位址轉為 NAND 實體位址，更新資料會寫入空閒頁並讓舊頁失效。GC 額外搬移造成 Write Amplification，WAF 以 SSD 寫入量除以 Host 寫入量衡量。資料配置可影響 GC 成本。
